# GITAM School of Architecture - Lab Slot Booking System

A real-time, cross-device web portal for booking laboratory time slots across Odd Semesters (I, III, V, VII, IX) for the GITAM School of Architecture.

## Key Features
- **Official Branding**: Styled with official GITAM colors (`#006654` Teal Green), typography (`Open Sans`), and corporate design structure.
- **Cross-Device Live Sync**: Powered by Firebase Realtime Database. Any slot booked on one device immediately updates and locks out for all other users without refreshing.
- **Odd-Semester Curriculum**: Complete curriculum course mapping for semesters I, III, V, VII, and IX.
- **2-Hour Slot Allocation**:
  - `08:00 AM - 10:00 AM`
  - `10:00 AM - 12:00 PM`
  - `01:00 PM - 03:00 PM`
  - `03:00 PM - 05:00 PM`
- **Monthly Matrix & CSV Export**: Provides an administrative monthly matrix view and one-click export to CSV/Excel.

## Hosting Instructions
1. Upload `index.html`, `style.css`, `app.js`, and `README.md` to your GitHub repository.
2. In GitHub, go to **Settings > Pages**, set **Branch** to `main`, and click **Save**.
3. Access your live site at `https://<your-username>.github.io/<repo-name>/`.
