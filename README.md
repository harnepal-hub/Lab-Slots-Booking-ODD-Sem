# GITAM School of Architecture - Lab Slot Booking System

A real-time, cross-device web portal for booking laboratory time slots across Odd Semesters (I, III, V, VII, IX) for the GITAM School of Architecture.

## Features
- **Official Branding**: Styled with official GITAM colors (`#006654` Teal Green), typography (`Open Sans`), and an embedded vector logo emblem.
- **Cross-Device Live Sync**: Powered by Firebase Realtime Database. Any slot booked on one device immediately updates and locks out for all other users in real time.
- **Odd-Semester Curriculum**: Complete curriculum course mapping for semesters I, III, V, VII, and IX.
- **2-Hour Slot Allocation**:
  - `08:00 AM - 10:00 AM`
  - `10:00 AM - 12:00 PM`
  - `01:00 PM - 03:00 PM`
  - `03:00 PM - 05:00 PM`
- **Monthly Matrix & CSV Export**: Includes an administrative monthly matrix view and 1-click export to CSV/Excel.
