# GITAM School of Architecture - Lab Booking System

Designed according to the official GITAM Deemed to be University web design system, featuring GITAM Maroon (`#800000`), Gold accents (`#D97706`), Open Sans typography, and real-time slot synchronization.

## Features
* **GITAM Web Design System**: Incorporates official color branding, fonts, and clean layout patterns matching `gitam.edu`.
* **Dynamic Slot Locking**: Instantly locks out filled 2-hour slots across all users in real time via Firebase.
* **Odd Semester Support**: Form options map directly to Semesters I, III, V, VII, and IX.
* **GitHub Pages Ready**: Static design requiring zero Node backend.
